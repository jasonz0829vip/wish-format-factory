如何使用

1. 选择或拖入文件。2. 输入“转成 PDF”等愿望。3. 点击开始转换，下载结果。

图片和 PDF 合并通常直接在当前浏览器处理，无需互联网。音频优先尝试设备本地处理。Office 转 PDF 使用本机 Windows 上的 LibreOffice：Windows 完整版无需其他电脑在线；该服务仅允许本机访问，不对局域网或公网直接开放。

PDF 可在手机离线提取可复制文字并保存为 TXT 或 Markdown；扫描件需要 OCR，当前不会输出空文本冒充成功。

手机需要完整 Word/Excel/PPT 转换时，可在联网状态下通过 Tailscale 私有 HTTPS 使用自己 Windows 电脑的 LibreOffice 引擎。

iPhone：请在 Safari 打开 HTTPS 网址，等待“离线资源已就绪”，点底部分享 → 添加到主屏幕。安装后开启飞行模式，可尝试已支持的图片、PDF、XMind 和设备可解码的音频转换。iOS 可能清理长期不用的缓存，需要联网重新打开一次。

Word、Excel、PPT 转 PDF 依然需要你自己的 Windows 电脑运行 LibreOffice；iPhone 断网时不能完成这些操作。未验收的格式会明确提示，不会伪造结果。

Windows 完整版新增混合压缩包分类整理：明确选择“文档/图片转 PDF、音视频转 MP3”或“Word/PPT 转 PDF、Excel 转 CSV、图片转 WebP、音视频转 MP3”；无法转换的原件仍会保留并列入报告。
